# Крипто-Капибара

HTML5 кликер/тайкун для **Яндекс Игр**. Vanilla JS, без фреймворков.

Тапаешь плоскую SVG-капибару, копишь КапиКоины, растишь фермы, делаешь ребирт, красишь капибару и дерёшься за топ.

## Что внутри

```
crypto-capybara-tycoon/
  index.html
  css/styles.css
  js/config.js        ← баланс, престиж, квесты, скины, имена лидербордов
  js/i18n.js          ← ru / en
  js/sdk.js           ← Yandex SDK + mock
  js/game.js          ← экономика, сейвы, UI
  assets/favicon.svg
  draft/CONSOLE.txt
  draft/icon.jpg
  draft/cover.jpg
```

## Цикл удержания

1. **Тап + комбо** — серия тапов даёт x1.5 / x2 / x3.
2. **Магазин ветками** — тап, майнинг, инфлюенсеры (автотап), стейкинг и NFT (+% ко всему).
3. **Ребирт** — сброс ферм и коинов, постоянный множитель (+8% за очко). Можно умножить очки за рекламу.
4. **Ежедневка + стрик** — 7 дней, день 7 жирный + скин. Пропустил день — можно спасти стрик за ролик.
5. **Квесты** — 3 дневных + недельный. «Посмотри N рекламы» крутит RV.
6. **Скины** — классика, магнат, астронавт, кибер, король, призрак (за рекламу).
7. **Ивенты** — выходные «Бычий рынок» x2.5, среда «Апельсиновый ажиотаж».
8. **Лидерборды SDK** — заработок / макс. CPS / ребирты.
9. **Асценсия** — после 8 ребиртов. Апельсины и китовый магазин, не сбрасывается обычным ребиртом.
10. **Альбом достижений** + комбинируемые аксессуары + 4 новых скина.
11. **Мини-игра «Брось апельсин»** + ивенты: бык / медведь / марафон / фестиваль.
12. **Soft IAP** — без interstitial, вечный +8%, стартовый пак, премиум сезона.
13. **Сезон / Battle Pass** — 21 уровень, фри + премиум. Крутится через `SEASON` в config.
14. **Same-day** — возвращение через 90+ мин (жирный мешок) и марафон дня (3 действия за 3 часа).
15. **5 квестов** разного веса + конфетти на крупных наградах.
16. **Ротатор режимов** (`MODES` + `EVENT_SCHEDULE` + `ROTATOR`): дождь, комбо-шторм, тихий кит, двойной ребирт, капи-бум, ночной рейд, уикенд.
17. **Челленджи:** спринт CPS, серия бросков, час без interstitial за апельсины, спасение стрика за 🍊.

Старые rewarded на месте: x2, мешок, оффлайн x2, «добить рекламой».

## Локальный просмотр

Открой `index.html`. `/sdk.js` не найдётся — это нормально, mock выдаёт награды сразу.

Настоящий SDK:

```
npx @yandex-games/sdk-dev-proxy -p .
```

## Загрузка в Яндекс Игры

1. ZIP: `index.html` в корне, латиница, без пробелов.
2. Консоль → добавить приложение.
3. **Реклама** → РСЯ (fullscreen + rewarded).
4. **Лидерборды** — создай три штуки, технические имена как в `js/config.js`:

   | Имя в Консоли | Что шлём |
   |---|---|
   | `cct_earned` | весь заработок |
   | `cct_cps` | лучший CPS |
   | `cct_prestige` | число ребиртов |

   Если имён нет, игра не падает: вкладка «Топ» покажет подсказку.
5. Облачные сохранения — отметь в черновике.
6. Тексты: `draft/CONSOLE.txt`. Иконка/обложка — отдельно, не в ZIP игры.

Авторизация в топ — только по кнопке «Войти в Яндекс» с понятным текстом (требование 1.2.1). Гостевой прогресс пишется локально и в облако без логина.

## SDK, не устаревший промпт

- `/sdk.js`, не `app-api/app.js`
- Interstitial только на паузе, кулдаун 3 мин. Не `setInterval`
- `LoadingAPI.ready()`, `GameplayAPI.start/stop`
- `player.setData` + `setStats`
- `ysdk.leaderboards.setScore / getEntries` (новый API, не `getLeaderboards()`)

## Баланс

Всё в `js/config.js`.

- Ребирт рано/поздно — `PRESTIGE.minRun` и `unit`
- Жирность очков — `perPoint` (сейчас 0.08)
- Ежедневка — массив `DAILY.rewards`
- Комбо — `COMBO.tiers`
